## 公开接口与核心边界

| 测试 | 接口与实际结果 |
| --- | --- |
| `local_and_git_copy_roundtrip_keeps_every_id_receipt_tombstone_and_body` | 两种 `export_copy`、两种 `import_copy`、`inspect_migration`、`MigrationReport`、`MigrationOrigin`：本地 → Git → 本地 → 重开与再次导出；新空间 ID，原业务及成员 ID、原回执、负零、转义正文、评论和附件墓碑一致；新空间可继续评论，源修订不变 |
| `resolved_git_proposals_and_both_blob_histories_survive_local_backup_and_git_bundle` | 两个真实仓库上传同附件 ID 的不同字节，冲突阻止导出；放弃提案后两份历史字节仍经本地备份恢复和 Git bundle 保留；被放弃请求不能借原 ID 在本地重执行 |
| `copy_permissions_new_id_and_existing_targets_preserve_the_source` | 只读导出、空 ID、复用源 ID、现有目标、源目录内部交换包或目标被拒绝；源和现有文件保留 |
| `malformed_packages_lineage_and_sqlite_origins_are_rejected_before_copy` | 损坏字节、元数据校验、格式、路径、缺失附件、额外文件、链接、SQLite 来源及回执损坏拒绝；失败没有目标落位 |
| `disabled_original_owners_stay_disabled_and_copy_origins_survive_remote_sync` | 所有者交接及停用后复制不复活旧权限；向本机真实裸远端同步，新副本获取后完整状态及来源一致 |
| `empty_histories_copy_and_origin_identity_frontier_and_checksum_are_validated` | 空空间、来源顺序、原操作缺失、前沿、校验值、无效 ID、重复来源及链长限制 |
| `resigned_manifest_still_requires_all_history_blobs_and_a_bounded_plain_tree` | 即使重算元数据校验值，缺历史附件清单仍拒绝；目录嵌套超限也拒绝 |

扩展 `complete_delivery_flow_is_persisted_in_sqlite`：从真实 SQLite 完成需求收集与评审、任务开发验收、测试失败、Bug 修复复测、产品验收、发布和后续改版，再备份恢复、复制为真实 Git 仓库，最后复制回新的 SQLite。比较完整规范状态，只调整工作空间 ID，发布快照和历史事实保持一致。原有服务真实 HTTP 完整流程及备份恢复也在最终回归重新通过。

## 权限修复与证据边界

新增 Unix 权限断言首次实测目录为 `0755`，未达到 `0700`。核查锁定的 tempfile 实现后，通过现有 Builder 显式设置创建权限；未新增依赖，也未自动更改已有用户目录。新建工作空间、备份暂存、外部解包、远端读取、迁移预检及服务恢复预检的临时根目录已明确使用 `0700`。修复后目录断言及最终全部测试通过。最终进程检查未发现本轮 FarFlow 测试服务或临时 PostgreSQL 遗留。

本轮是库接口及后端证据，完整三模式迁移未完成。服务账户映射、服务导入导出、正式停写与完成凭据、迁移 CLI、客户端向导、真实界面验收、规模性能、断电及三平台均待继续。完整客户端、用户管理界面、打包和禅道最终比对也未完成。
