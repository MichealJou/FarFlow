## 公开接口与边界测试

| 接口或能力 | 对应测试及实际结果 |
| --- | --- |
| `Server::connect`、数据库与目录绑定 | `database_and_files_cannot_be_swapped_or_copied_to_another_directory`：同目录并发重连成功；错误目录、复制到另一位置、另一数据库复用目录均拒绝；配置链接解析到相同规范路径可重连 |
| 待初始化与标记丢失 | `pending_initialization_recovers_but_ready_storage_cannot_be_recreated`：待初始化身份可在同目录恢复；就绪标记丢失不能自动重建；未含业务的待初始化目标可重新选择目录 |
| 运行中保护与旧格式 | `existing_unbound_data_needs_migration_and_runtime_marker_loss_stops_business`：运行中丢标记后创建空间失败且库中无新空间；已有账户但未绑定时拒绝自动接管 |
| 标记文件边界 | `marker_is_atomic_private_and_rejects_wrong_identity_or_tampering`：原子落位、幂等、`0600`、错误身份、坏内容、缺失和超长均核对 |
| `Server::backup`、`Server::restore`、`RestoreResult` | `service_backup_restores_accounts_all_spaces_raw_payloads_and_retry_receipts`：两空间、临时密码、停用、账户历史、原始负零与转义内容、附件、持久幂等回执均恢复；源会话失效；相同恢复重试返回已完成而不覆盖后续账户 |
| 中断恢复 | `interrupted_restore_rolls_back_database_blocks_bootstrap_and_resumes_same_backup`：注入目标约束失败后业务表回滚、恢复状态未完成；启动与初始化被拒绝；另一备份不能混用；移除故障后同一备份重试成功 |
| 损坏及语义校验 | `damaged_or_rewritten_packages_fail_before_touching_the_restore_database`：文件内容损坏、重算哈希但日志缺失或格式错误、异常密码参数、路径穿越均在目标恢复状态写入前拒绝 |
| 权限、路径与真实可执行命令 | `backup_authorization_destinations_and_executable_commands_are_real`：无效、临时密码及普通账户会话拒绝；内部路径及已存在目录拒绝；原文件保留；真实二进制完成备份和恢复，重复恢复无覆盖，输出不含令牌 |
| 在线一致快照 | `online_backup_keeps_one_snapshot_while_business_and_attachments_continue`：通过真实数据库表锁确认备份已取得快照并等待；此时普通业务保存评论、上传新附件成功；恢复仍与修改前完整状态一致，源空间保留新变化 |
| 分页及零空间 | `account_and_event_paging_and_zero_workspace_backups_restore_without_truncation`：502 个账户及 502 条历史跨越 500 条分页完整保存恢复；零空间有效；恢复后新增账户的历史序列继续增长 |
| 共享文件公开函数 | `shared_backup_file_operations_are_bounded_private_and_reject_links`：直接测试 `regular_directory`、`read_file`、`hash_file`、`write_json`、`valid_hash`，含精确读上限、超限、不可覆盖、私有权限、文件及目录链接拒绝 |
| JSONL 及路径核心边界 | `json_line_limits_require_complete_records_and_stop_after_the_first_error`、`backup_paths_and_tree_entries_cannot_escape_through_components_or_links`：精确 16 MiB、超限、缺换行、非法记录、深层目录、特殊路径和链接拒绝 |

## 真实网络完整交付再恢复

扩展 `full_delivery_runs_through_service_roles_and_replays_from_postgres_after_reconnect`。原有独立服务上的真实 HTTP 交付链保持：需求收集与评审、任务开发与验收、用例、构建、失败执行、Bug 修复与独立复测、产品验收、发布、评论回复提及、附件及后续改版。

完成原服务重启和原始日志重放核对后，调用实际备份接口导出全部服务数据，恢复到另一临时数据库及独立目录，再启动另一真实可执行服务进程。实际验证：原会话返回 401；新登录后核心完整状态逐字规范编码一致；验收附件字节一致；恢复后可追加回复。各独立 HTTP 服务通过 SIGINT 成功退出。

其他集成用例调用实际 Axum 路由并连接真实 PostgreSQL 和文件系统；CLI 用例调用编译产物。它们不替代上述真实 HTTP 网络证据。最终进程检查没有发现本轮遗留的 FarFlow 测试服务或临时 PostgreSQL；发现的其他项目任务未操作。
