## 接口与边界证据

| 范围 | 实际测试 |
| --- | --- |
| `Server::connect`、`router` | 真实数据库和独立附件目录；重连及真实进程重启；不兼容载荷格式拒绝启动 |
| 核心公共附件接口 | `write_attachment_bytes`、`read_attachment_bytes`、`sync_directory` 的直接调用、真实内容、哈希及大小异常 |
| 空间创建和隔离 | 初始化幂等、同 ID 不同参数拒绝、列表按成员过滤；系统管理员不能绕过空间成员身份 |
| 身份与成员 | 拒绝伪造操作者与时间；成员资料取真实账户；所有者与工作空间版本校验，停用成员立即拒绝读取 |
| 用户与所有者交接 | 停用最后有效所有者被拒绝；并发账户停用与另一个所有者降权，最终仍有一位有效所有者 |
| 指派和提及 | 已停用服务账户、非空间成员拒绝；只读成员不能修改业务 |
| 幂等及并发 | 持久请求重连后返回原回执；不同请求或不同操作者复用 ID 冲突；旧工作项版本并发修改仅一个成功 |
| 事务失败 | 日志写入失败时投影回滚；附件写入后数据库失败只留下无引用文件，相同请求可重试 |
| 数据校验 | 投影校验值损坏、原始操作缺失、回执被改写均明确报错；不返回伪造成功 |
| JSON 精确性 | 负零、合法换行及制表符保存后指纹不变；将同一请求载荷的 `-0.0` 改成 `0.0` 会冲突 |
| 目录查询 | 真实 105 个匹配账户分两页返回，无重复；下划线按字面匹配，基础资料不含权限标记或密码字段 |
| 附件 | 实际字节、两个文件名去重、中文名下载、跨空间隔离、未登录和只读用户上传拒绝 |
| 附件边界 | 精确 10 MiB 上传下载成功，超限拒绝；元信息伪造含嵌套批次拒绝；缺失字节可由相同上传补回，损坏字节拒绝覆盖 |
| 附件可见性与路径 | 对象归档及附件墓碑阻止下载并保留字节；链接目录不会向外写文件；Unix 新建目录权限为 `0700` |
| 请求容量 | 约 60 KiB 的中文正文业务请求成功，超过 2 MiB 的业务请求被拒绝，账户接口仍沿用 16 KiB 上限 |

## 真实网络完整交付

`full_delivery_runs_through_service_roles_and_replays_from_postgres_after_reconnect` 在独立可执行服务进程上，通过 Hyper 客户端发送真实 HTTP，按真实账户分别执行所有者、开发和测试职责：

创建空间 → 注册并绑定成员 → 产品、项目、迭代 → 收集需求并转正式需求 → 评审 → 开发任务开始和提交验收 → 测试验收任务 → 用例评审 → 构建与测试单 → 测试失败转 Bug → 开发确认和修复 → 新执行回归通过 → 独立复测关闭 → 产品验收 → 固定发布快照 → 上传证据 → 评论、提及和回复 → 后续需求改版。

开发自行验收任务被实际接口拒绝。后续需求改版不会改变已发布快照。测试向服务发送 SIGINT，等待成功退出，再以相同数据库和目录启动新进程；新进程读取的完整状态一致。随后测试独立从数据库初始状态和全部服务端原始请求进行核心重放，与当前投影逐项比较一致。

其余集成测试直接调用实际 Axum 路由，连接真实 PostgreSQL 和文件系统；它们与上述独立进程网络证据分开记录。测试客户端使用现成 Hyper 库，没有自行实现 HTTP 解析来替代完整链路验收。
