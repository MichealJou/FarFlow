## 新公开接口对应测试

| 接口 | 对应验证 |
| --- | --- |
| `LocalWorkspace::prepare_transfer` | 备份先于格式升级；冻结、幂等重试、权限及输入边界；事件写失败和错误屏障均完整回滚 |
| `LocalWorkspace::transfer_status`、`transfer_events` | 原生无记录、冻结／取消／完成状态、事件不含令牌；校验事件和当前阶段；损坏拒绝 |
| `LocalWorkspace::export_transfer` | 固定切点、相同包重试、独立目录、其他包保护、未冻结／取消拒绝；实际字节核对 |
| `LocalWorkspace::complete_transfer`、`cancel_transfer` | 错误回执、角色、计划及时间拒绝；完成后源只读；取消不发凭据；同计划重试不重复事件 |
| `GitWorkspace::stage_transfer` | 正式包、目标模式、实际操作者与时间校验；保留原空间和业务 ID，拒绝非所有者与普通复制包；不覆盖不同目标 |
| `GitWorkspace::transfer_status`、`activate_transfer` | 只读暂存、错误凭据和越权拒绝；完成后才激活；冷启动、文件包、裸远端及重复暂存保留阶段和后续数据 |
| `MigrationArchive::transfer_plan`、`transfer_history` | 普通包无计划、正式包目标及切点匹配；三种普通复制入口的共享转换拒绝正式包 |
| `MigrationHistory::export_transfer` | 历史前沿重建、原始字节、固定计划；切点后变化拒绝；完整交付后正式交接 |

迁移计划、阶段、回执及完成凭据的编码、未知字段、模式、历史身份、前沿和令牌边界由 `transfer` 模块单测及实际适配器测试共同覆盖。

## 四项适配器专项测试

`crates/core/tests/transfer.rs`：

1. `local_to_git_handoff_preserves_ids_bytes_and_blocks_both_sides_until_completion`：完整本地状态含原始正文、负零、成员和真实附件。冻结后原连接及另一个已打开的本地句柄均不能写；不能按普通复制绕过。Git 暂存保留同一空间 ID，实际附件可读，但业务、决策、提交、导出和推送均拒绝。错误凭据和越权不能激活。源完成后仍只读，合法目标激活后可评论；完成与激活重试不重复。文件包、冷启动及真实裸远端副本保留激活状态，完整源备份恢复继续只读。
2. `cancellation_restores_only_the_source_and_old_targets_never_gain_a_completion_token`：当前源实例取消后恢复写入，既有暂存目标继续只读；不能从该已取消源获得完成凭据。新计划与旧回执不能混用。迁移中完整备份恢复保留冻结状态，并可按原计划继续交接；新计划凭据不能激活旧计划。
3. `sqlite_fence_also_blocks_previously_opened_sql_connections_and_rolls_back_failed_preparation`：在冻结前打开实际 SQLite 连接，冻结后五张业务表的 INSERT、UPDATE、DELETE 均被触发器拒绝。注入事件写入失败及旧库同名错误触发器，核对冻结事务回滚、数据库版本不升级、源仍可正常工作；修复测试注入后可重新冻结。取消后正常写入恢复。
4. `invalid_roles_inputs_existing_destinations_and_corrupt_control_are_rejected`：拒绝未冻结导出、空 ID、相同源／目标模式、负时间、非所有者、普通复制包及不同既有目标。控制校验值、只读标记、令牌、屏障或事件损坏时失败，损坏状态不生成成功备份。

核心新增两项单测另验证空空间、伪造身份和模式、缺失前沿、计划指纹、阶段组合、错误凭据、时序及历史所有者。目标后续交接所有者，不会把过去的合法迁移操作者错误判为未授权。
