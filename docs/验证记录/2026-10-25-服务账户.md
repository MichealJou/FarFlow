## 公开接口和运行证据

| 接口或范围 | 直接证据 |
| --- | --- |
| `Server`、`connect` | 每个集成测试均连接独立真实数据库；再次连接保留账户和会话；无效地址返回安全错误 |
| `bootstrap` | 两个并发初始化仅一个成功；账号、姓名和密码边界；禁止重复创建初始管理员 |
| `router` | 真实路由验证认证、账户全部接口、错误、权限、历史、缓存头；另有独立进程真实 HTTP 登录 |
| 启动程序 | 实际调用帮助、错误参数、初始化和启动命令；回环 HTTP 登录成功；Unix SIGINT 后进程正常退出 |
| 默认监听 | 默认仅回环地址、端口 4640；临时端口、IPv6 回环有效；空值、域名及超范围端口拒绝 |

`executable_initializes_admin_and_serves_real_http_until_graceful_shutdown` 启动编译后的独立可执行文件，通过环境连接临时数据库并初始化管理员，再启动回环服务。测试用实际 TCP 连接发送 HTTP 登录，核对账号和令牌长度，最后发送 SIGINT 并等待成功退出，没有用路由模拟替代此项运行证据。

## 用户流程与边界

- 数据库口令字段为 Argon2id PHC；相同密码的两次哈希不同，正确和错误密码均验证。会话数据库只保存 SHA-256，原始令牌不入库。
- 新建和重置后必须改密。本人改密校验原密码；改密、重置、停用及管理员权限变化撤销旧会话，跨两个服务实例立即生效。重新启用不恢复旧令牌。
- 不存在账户、错误密码和停用账户的登录结果一致。连续失败触发真实数据库限流，过期会话返回未登录。
- 普通账户不能列出、创建、修改、提权或重置服务账户；匿名请求拒绝，伪造操作者字段拒绝。
- 最后一位管理员不能停用或降权。两个管理员并发撤销自身权限，仅一个成功，数据库仍保留一位有效管理员。
- 相同资料版本的两个修改仅一个成功；另一个明确冲突。普通资料更新后的当前会话读取到新资料。
- 建号、改密、重置及资料修改生成可追溯记录，分页读取完整历史。列表和历史不返回密码哈希、密码或令牌。
- 人为移除临时测试库的审计表后，资料更新返回失败且姓名、版本没有改变，证明账户和审计共用事务。此故障只发生在隔离测试库。
- 请求体超限、未知字段、无效标识、重复账号、非法内容和不存在对象均有测试；接口错误采用中文，不泄漏数据库内部详情。
