# 共享界面与浏览器运行

2026 年 10 月 25 日。当前已有可运行的 React + TypeScript 界面，入口位于 `apps/web`，业务组件位于 `packages/ui`，HTTP 访问位于 `packages/client`。没有把 Rust 状态机再写成一套前端业务规则。

## 已接入范围

- 三模式选择入口。浏览器使用服务模式；本地和 Git 明确提示需要桌面文件访问能力，不提供虚假的初始化成功。
- 服务登录、首次改密、退出、空间选择和创建。会话令牌仅放在内存，不写入本地存储。
- 产品、模块、项目、迭代、收集箱、需求、计划、任务、用例、测试单、执行记录、构建、Bug、发布和文档的列表、搜索与筛选。
- 正常业务字段表单；需求关系固定内容版本，用例使用步骤及预期结果，测试单绑定构建和用例，发布包含需求、修复 Bug、构建、测试单及有说明的遗留问题。
- 独立状态动作：评审、产品验收、收集转化、任务交接、执行测试、由失败结果提交 Bug、解决方案、独立复测和发布。服务核验版本、权限和门禁，错误保留表单。
- 评论、回复、提及、评论编辑删除、附件引用、上传下载、预览和动态。单个附件不超过 10 MiB。
- 服务用户创建、更新、管理员设置、停用、重置密码和审计；工作空间成员使用真实服务账号绑定角色。迁移历史成员 ID 不被新账号 ID 替换。
- 需求验收版本、Bug 解决与独立复测记录、不可改写的发布快照均可查看。

默认配色为 `design/previews/v3-03-浅灰钴蓝.png`。其他十一套方案可在设置中切换，偏好仅保存在当前设备。窗口较窄时侧栏收为图标，表格在自身区域滚动，创建表单可滚动操作。

## 实际使用的依赖

React 负责共享页面，Vite 负责开发和构建，TypeScript 检查访问协议。Radix Dialog 提供对话框焦点和键盘行为；Tabler 提供与选稿相近的图标；其余样式使用普通 CSS，表单使用浏览器控件。当前没有为尚未需要的表格和样式能力安装 Tailwind、shadcn 或 TanStack Table。

测试使用 Vitest、V8 覆盖率、Testing Library 和 jsdom；组件测试不替代真实浏览器验收。品牌图片来自已选稿约束下生成的独立资产，保存在 `apps/web/public/assets/farflow-mark.png`，已实际用于页面。

## 本机开发

已有独立服务运行时，项目根目录执行：

```sh
npm ci --registry=https://registry.npmjs.org
npm run dev -- --host 127.0.0.1 --port 14730 --strictPort
```

开发入口把 `/api` 转发到 `http://127.0.0.1:4640`，可用 `FARFLOW_PROXY_URL` 配置开发服务。页面默认连接当前来源，服务接口仍需真实账号登录。初始化管理员与数据库配置见[服务运行](10-服务账户与运行.md)。不要把数据库地址或会话令牌写进前端构建。

```sh
npm run typecheck
npm run test:coverage
npm run build
```

构建输出在 `apps/web/dist/client`。当前开发代理用于本机运行；服务端静态资源托管、生产浏览器部署、Tauri 文件访问、Git 同步中心和迁移向导还没有交付。保留的 Sites 兼容打包脚本及其四项测试不代表已部署网站。

当前证据见[共享界面验证](验证记录/2026-10-25-共享界面.md)及根目录 `design-qa.md`。这些证据仅覆盖所列浏览器流程，完整交付仍以[交付矩阵](05-交付进度.md)为准。
