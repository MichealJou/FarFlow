# Git 远端同步

实现位于 `crates/core/src/repository/remote.rs`，继续使用共享核心和系统 Git。取消与超时控制位于相邻 `transport.rs`，复用 `process-wrap` 的标准库接口处理进程组和 Windows 作业对象。业务保存、Git 提交和上传结果分别保留；本地与 Git 模式不要求运行 FarFlow 应用服务。

## 接口与行为

| 接口 | 实际行为 |
| --- | --- |
| `GitWorkspace::from_remote` | 获取 `main` 到临时裸仓库，验证历史、路径、附件及操作图后创建新副本；生成新设备身份 |
| `pull` | 先检查当前成员，从当前仓库获取到唯一内部引用；通过同一文件包校验与业务合并流程安装，最后清理内部引用 |
| `push` | 锁内检查权限并固定一次本机提交，锁外上传这个提交的确切 ID；不使用强制上传 |
| `sync` | 检查远端是否为空，必要时获取合并，再上传；遇到非快进最多执行两轮，持续竞争时返回失败和保留的本机提交 |

`GitPush` 包含固定提交 ID、是否上传、失败类别及中文说明。失败分为非快进、认证、传输和远端策略拒绝。原始 Git 标准输出及错误输出用于内部分类，不回传业务界面，避免凭据助手的原始消息带出令牌。

`GitSync` 同时返回业务视图、上传结果和 `pending_local`。上传过程中允许继续本机保存；如果上传的固定提交不包含这些新记录，返回 `pending_local=true`。上传成功与本机仍有待同步变化可以同时成立。

四个入口均有 `*_with_control` 版本，可传入同一 `GitTransport`。默认截止时间为 120 秒，允许配置大于零至十分钟；获取、上传及有界重试共用截止时间。控制对象可克隆，取消会通知同一次操作。网络输出分别限制为 1 MiB，并行读取 stdout 和 stderr，避免等待管道造成卡住。取消时终止整个传输进程组，避免只结束 Git 父进程后仍等待 HTTP／SSH 子进程的输出。

取消不回滚已经完成的本机原子写入；远端可能已经接受上传，错误提示要求重试同步核对结果。没有远端确认时不能宣称未上传或已上传。桌面仅获取、仅上传时不计算后续本机变化，返回未知状态，只有完整同步返回已核对的 `pending_local`。

Git 源开始[正式交接](18-Git源交接与冻结确认.md)后，业务写入被屏障拒绝，提交与同步仍可传播冻结、成员确认及取消。迟到业务会保留并标记，阻止旧计划首次完成；已知并行冻结计划不会被自动选胜。同步成功不表示空间已解冻，状态和确认进度须从源迁移查询接口读取。

非快进采用重新获取双方历史后合并上传，遵循 [Git 上传规则](https://git-scm.com/docs/git-push)。业务正文或状态冲突仍进入操作图问题集合，需要明确决策，不能以 Git 上传成功冒充业务冲突已解决。

## 地址与身份

接受本机仓库、绝对 `file://` 地址、HTTP、HTTPS、SSH、Git 协议和 SSH 的主机别名语法。具体传输交给系统 Git；不自行实现 SSH 或 URL 解码。

拒绝地址中的 HTTP 用户名或令牌、SSH 内嵌密码、查询参数令牌、控制字符、非法主机和外部协议助手。身份通过系统 Git 凭据助手、SSH 配置及代理提供。网络调用保留用户的系统配置；已有副本还复用当前仓库的凭据助手。创建新副本时没有目标仓库配置，使用系统配置。[Git 凭据文档](https://git-scm.com/docs/gitcredentials)说明助手和配置层级。

业务成员身份与托管访问凭据分开。Git 模式以可信团队和仓库权限为边界；服务账户密码、会话、管理员身份不进入数据仓库。

## 校验与恢复

所有接收内容复用文件包校验，不检出或执行接收仓库的文件。未知路径、符号链接、可执行文件、错误工作空间、内容哈希异常、缺失操作依赖和不可变历史删改均拒绝安装。

远端拒绝、断连或竞争不会撤销本机已保存的业务与提交。`push` 返回明确失败，用户可重试；`sync` 不强推，不无限循环。获取或认证失败通过错误返回，不生成已上传结果。

## 当前证据和限制

已验证真实本机裸仓库、`git://127.0.0.1` 端点、HTTP Basic 与系统凭据助手、双副本附件、断连、远端策略拒绝、上传竞争和上传期间本机保存。测试全部使用临时目录、回环地址与假凭据，未连接真实公司或公网仓库。

普通系统 `git clone` 不保存空目录，打开时会恢复 `operations`、`attachments` 容器。仍核对已提交文件和附件哈希；已提交操作、附件被删或容器被换为符号链接时拒绝打开。普通克隆空空间、无附件空间及克隆后续写均已有测试。

新增真实无响应 HTTP、上传中取消、继承管道子进程清理和重试恢复验证。原生同步中心已有完整同步、仅上传、仅获取、双副本记录接续、后台读取业务和手动取消证据。SSH、HTTPS 托管登录与 TLS、系统钥匙串弹窗、实际托管限额、跨平台安装与批量性能仍未验收。原有传输证据见 [验证记录](验证记录/2026-10-25-远端同步与标准复测.md)，新界面和退出处理见[桌面 Git 同步](22-桌面Git同步.md)。
